# Pronunciation and audio recommendation

Use sourced IPA as reference data and **downloadable, tested recordings for predictable listening practice**. Offer device Dutch TTS as a convenient fallback after checking the actual voice on the actual device. The existence of a Dutch voice, an API or an offline flag does not establish pronunciation quality. No listening-quality experiment was performed in this research, so “Android/browser TTS is good enough” remains unverified for the family's devices.

For the first release, package only audio that has passed the test below. Missing audio disables listening/spelling-from-audio tasks while leaving eligible written tasks usable (T43). Blueprint §15 precedence remains: approved downloaded audio → confirmed usable local Dutch TTS → explicit online-audio choice → unavailable. Cache/version/hash media independently of lexeme identity (W21/F08). Prefer sentence audio for meaning and connected speech, plus isolated headword audio for focused pronunciation. Distinguish those purposes.

## A concrete QA experiment

Use at least 30 stimuli spanning /ui/, /eu/, /g/, stress and unstressed vowels, short/long-vowel contrasts, singular/plural, names/service abbreviations, question intonation, separable forms, numbers and half drie. Compare an approved source recording and each candidate engine on those exact texts. Preserve WAV/OGG, voice/version/rate, device/browser build, network state and outcome. Verify start/end trimming, volume, clipping, text identity, offline replay, locale fallback and interruption/resume.

For a team without Dutch speakers, source audio provides a reference but machine-ASR agreement is only a diagnostic. If an independent audio-capable reviewer is actually available, ask it to compare pronunciation/stress/meaning to the source without knowing which engine is preferred, and record uncertainties. Without such a reviewer, mark pronunciation QA incomplete; do not make TTS-generated audio authoritative for IPA or pronunciation grading. Listening comprehension can be piloted privately with transparent status, but no unearned curated-audio badge.

Polish-friendly pronunciation can be added later as an approximate aid, separately from IPA and audio. It should not silently collapse Dutch distinctions into Polish spelling. No fabricated approximations were inserted in this pilot.
