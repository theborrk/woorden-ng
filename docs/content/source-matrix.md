## Import traps found in real records

1. English-edition `opstaan` includes `forms` items such as `irregular separable strong`, tagged `table-tags`. These are metadata, not valid Dutch answers.
2. Dutch-edition conjugation extraction includes items such as `ev.` and combined auxiliary/table strings. Use a positive grammar-feature allowlist and retain raw source records for adjudication.
3. Dutch and English extracts can use different IPA conventions. Do not edit vowel length or regional variants to make a comparison pass.
4. Polish `afspraak` headword presence does not verify its appointment sense. A lemma hit must never become a blanket translation approval.
5. Tatoeba joins produce translation candidates, not CEFR labels, unambiguous cloze tasks, or automatically validated answer offsets.

The source snapshot and the interpretation rule are both part of provenance. A fetched file alone is not a linguistic reviewer.

## Job assignment after comparison

Ranking uses NT2Lex exposure plus SUBTLEX lemma/POS/CD and an explicit practical-utility policy. Grammar uses **ODWN explicit article fields plus Kaikki forms**, with Apertium/targeted language advice for adjudication. Tatoeba supplies example candidates; constrained original examples fill coverage gaps. EN glosses come primarily from the English Wiktionary edition; PL evidence comes from the Polish edition when the same sense exists, otherwise direct model-authored translation with independent review. No acquired resource provides a complete trustworthy NL–PL–EN A1–B2 deck.

Bulk measurements above were obtained in phase 1 and are retained in `research/content-2026-10/evidence/source-inspection.json` and manifests. Two later local bulk copies (English Kaikki and Dutch-edition gzip) were incomplete; the delivery uses preserved, valid record excerpts rather than silently recounting partial files. Only complete JSON records from the valid English prefix supplied a few additional pilot headwords. Production imports must re-fetch and validate the full pinned files. The bundle contains the actual excerpt set used for the audit and pilot, not a claim that an incomplete local bulk copy is complete.
