# Legacy reference (read-only)

The original Woorden app by [iamsergeyka](https://github.com/iamsergeyka/woorden), exactly as it was
at commit `e66ad1551a91ee31fe354a33a03cbfff4a66030d` (the blueprint's verified baseline), moved here
unchanged so the new app can be built next to it:

- `index.html`: the whole original app (seed data, UI, scheduling, storage) in one file
- `README.md`, `screenshots/`: the original README and screenshots
- `download`: the original repository's intended `.gitignore`, uploaded under this name

Nothing here is built, deployed or edited. Tools read `index.html` to extract the seed content into
fixtures (blueprint W01/W07). The MIT license of the original stays in the root `LICENSE`.
